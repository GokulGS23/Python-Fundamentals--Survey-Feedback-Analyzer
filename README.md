Python Assignment - Text-Based Feedback Analysis Tool

Description

This assignment focuses on collecting, cleaning, and analyzing customer feedback using Python functions, data structures, string manipulation, and basic data analysis techniques.

- Adding and Modifying Dictionary Elements
- User Input and Type Conversion
- Functions and Function Definition
- Function Parameters and Return Values
- String Manipulation and Text Cleaning
- Removing Punctuation
- Removing Extra Spaces
- Converting Text to Lowercase
- Lists and List Comprehensions
- Loops and Conditional Statements
- Searching for Words in Feedback
- Counting Feedback Entries Containing a Word
- Calculating Average Ratings
- Finding the Longest Feedback
- Set Creation and Operations
- Removing Duplicate Words Using Sets
- Generating Summary and Insights
